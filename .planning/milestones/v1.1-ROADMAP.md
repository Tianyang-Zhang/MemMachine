# Milestone v1.1: Sufficiency-Aware Skill Verification

**Status:** SHIPPED 2026-03-04

## Overview

This milestone added sufficiency-aware observability across top-level and
sub-skills, introduced LLM-led filtering metadata contracts, added split live
verification with optional rerun, and validated behavior with a 100-question
WikiMultiHop benchmark gate.

## Milestone Summary

**Decimal Phases:** None

**Key Decisions:**
- Parent sufficiency is computed independently from child `is_sufficient`.
- Runtime keeps full retrieved episode sets; LLM emits filtering/sufficiency
  metadata for metrics/debug/eval.
- Split runs one live verification pass after branches and can request one rerun
  pass.

**Issues Resolved:**
- Added first-class top-level sufficiency signals in runtime outputs.
