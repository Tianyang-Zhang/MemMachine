# Phase 03.2 Research

## Current State Findings

- `evaluation/utils/agent_utils.py` manually built legacy top-level agents and
  defaulted retrieval mode to `ToolSelectAgent`.
- Benchmark entry scripts (`wikimultihop_search.py`, `hotpotQA_test.py`,
  `longmemeval_test.py`, `locomo_search.py`, and
  `tool/wikimultihop_skill_search.py`) passed `ToolSelectAgent` for retrieval
  mode.
- `service_locator.py` still allowed explicit legacy top-level route returns.

## Implementation Strategy

- Replace evaluation helper top-level construction with
  `create_retrieval_agent(...)` for retrieval mode.
- Preserve explicit `MemMachineAgent` bypass for baseline mode.
- Normalize benchmark metric aggregation to tolerate `RetrieveSkill` fields
  (`selected_skill`, `route`, `agent`) when `selected_tool` is absent.
