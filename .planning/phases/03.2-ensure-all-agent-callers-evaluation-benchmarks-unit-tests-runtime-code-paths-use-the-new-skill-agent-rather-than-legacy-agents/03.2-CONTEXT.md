# Phase 03.2: Legacy Caller Cutover to Skill Agent - Context

**Gathered:** 2026-02-28
**Status:** Ready for planning/execution

## Phase Boundary

Cut over all retrieval-agent callers so retrieval mode always goes through
`RetrieveSkill` runtime wiring. Keep direct memory bypass mode for benchmark
baselines only.

## Locked Decisions

- Retrieval benchmark/evaluation scripts must construct `RetrieveSkill` as the
  retrieval path entrypoint.
- `MemMachineAgent` is allowed only for explicit `memmachine` baseline mode.
- Unit tests that validate service locator routing must no longer assume
  top-level legacy route selection (`ToolSelectAgent`, `SplitQueryAgent`,
  `ChainOfQueryAgent`).

## Risks

- Metric consumers still expecting legacy top-level names may break.
- Evaluation scripts may silently fall back to unknown tool labels without
  compatibility shims.
